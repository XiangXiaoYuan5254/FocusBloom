How it works

目标不是硬撑得更久，
而是越来越了解自己的注意力。

在你设定的区间里，提示音会随机响起。你无法预判它，所以每一次响起，都是一次诚实的自我检查：刚才，我还在吗？

一轮 60 分钟的专注

本轮共 14 次随机提示，平均间隔 4.0 分钟

015304560 分钟
随机提示 + 10 秒微休息 记录走神 记录疲劳
  1. 01

    设计这一轮

    选择任务、专注时长和随机提示区间，再标记一下开始前的精力。开始后设置会锁定，避免反复调整。

  2. 02

    随机提示，微休息

    提示音在区间内随机响起，随后是十秒微休息：闭眼、松肩、慢呼吸。计时只统计净专注时间。

  3. 03

    一键记录走神

    注意力掉线了？点一下「我走神了」或「我开始累了」。发现走神，本身就是注意力回来了。

  4. 04

    复盘，然后进步

    每轮结束记录评分、精力变化和备注。洞察会估计你的稳定专注时长，并给出下一轮的建议。

Privacy

你的注意力数据，
只属于你。

专注芽不需要注册，也不连接任何服务器。每一轮记录都只保存在你的 Mac 上，随时可以导出为 CSV，或者整个删掉。

数据位置 ~/Library/Application Support/FocusBloom/focus-data.json
  • 不需要注册或登录

    没有账号体系，也就没有需要保护的密码。

  • 不上传专注记录

  • 不含分析 SDK 或广告

    没有埋点，没有推荐位，只有你和你的任务。

    一键导出 CSV，用你喜欢的工具继续分析。

FAQ

常见问题

没找到答案？欢迎到 GitHub Issues 提问。

打开时提示“无法验证开发者”怎么办？

专注芽使用本地签名，尚未经过 Apple 公证，这是 macOS 对所有未公证 App 的默认提示。打开「系统设置 → 隐私与安全性」，在页面下方找到专注芽，点击「仍要打开」即可。macOS 14 上也可以按住 Control 点按 App，选择「打开」。

熟悉终端的话，也可以运行：

xattr -dr com.apple.quarantine /Applications/专注芽.app
需要联网或注册账号吗？

都不需要。环境音已内置在 App 中，棕噪音由本机实时生成。唯一会和其他 App 交互的，是你主动开启的「专注结束后播放音乐」。

我的数据保存在哪里？怎么备份或删除？

所有记录保存在 ~/Library/Application Support/FocusBloom/focus-data.json。你可以直接备份这个文件，也可以在 App 中导出 CSV。

删除 App 不会自动删除数据文件；如需彻底清除，手动删除 FocusBloom 文件夹即可。

为什么会请求控制“音乐”或“辅助功能”的权限？

只有开启「专注结束后自动播放音乐」时才需要。使用 Apple Music 时，macOS 会询问是否允许专注芽控制“音乐”App；使用网易云音乐时，需要在「系统设置 → 隐私与安全性 → 辅助功能」中允许专注芽。不开启这个功能，就不会有任何权限请求。

“专注能力”是医学诊断吗？

不是。它是根据你近期走神前时长、完成率、主观专注评分和精力变化给出的个人趋势估计，用来帮你安排下一轮，而不是给自己贴标签。

支持 Intel Mac 或 Windows 吗？

目前的安装包面向搭载 Apple 芯片、运行 macOS 14 或更高版本的 Mac。Intel Mac 可以按上面的步骤从源码构建。暂不支持 Windows。
